# Launching the Spot Driver

To launch the driver for Spot, execute the following command in a terminal:

```bash
ros2 launch spot_bringup bringup.launch.py hostname:=192.168.50.3
```

## Basic gamepad controls
Back + Start -> Claim lease/leash
Y -> Power on
A -> Toggle between standing or seating robot
RB + Joysticks -> Arm control
LB + Joystick -> Body control
Back Arrow -> Stow arm
Front Arrow -> Deploy the arm to Ready pose
